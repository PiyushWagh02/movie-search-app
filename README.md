# 🎬 Movie Search App

A simple movie search app built with **HTML, CSS, and JavaScript**.  
Currently uses a local `movies.json` file as the data source.

## 🚀 Features
- Search movies by name  
- Responsive grid layout  
- Hover effect on movie cards
